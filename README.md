# edu-hk-public-info

Reference materials on Hong Kong primary/secondary education curricula, starting with the AI-related portion of the primary Information and Innovation Technology curriculum framework.

## Contents

| File | Description |
| --- | --- |
| `IIT_Summary_on_AI_TC.md` | 小學資訊與創新科技課程框架 — 人工智能部分（試行版）summary, in Traditional Chinese. |
| `IIT_Summary_on_AI_TC.pdf` | PDF rendering of the same document. |

## Source

The document is an excerpt of the AI portion of the Information and Innovation Technology curriculum framework, drafted by the 「檢視小學階段科技教育專責委員會」 and reviewed by the 「科技教育委員會」 under the Curriculum Development Council. It is intended to help schools pilot the AI portion of the primary curriculum.
